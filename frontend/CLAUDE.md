Default to using Next.js with npm.

- Use `npm run dev` to start development server
- Use `npm run build` to build for production
- Use `npm run start` to start production server
- Use `npm install` to install dependencies
- Use `npm test` for testing

## APIs

This project uses Next.js with:
- Express for the MCP server backend
- React for frontend components
- Tailwind CSS for styling
- MDX for markdown content

## Frontend

This is a Next.js application. Use the standard Next.js development workflow:

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

The frontend uses:
- React 18 with TypeScript
- Tailwind CSS for styling
- Radix UI components
- MDX for markdown rendering
